=== Speed Analyzer – Full Changelog ===

= 1.19.0 =
* Total Blocking Time (TBT) replaces INP in all lab measurements, matching what Google PageSpeed Insights now reports.
* TBT uses Lighthouse's per-device thresholds: 200/600 ms on mobile, 150/350 ms on desktop.
* The Core Web Vitals field assessment continues to report INP, which is measured from real users. TBT has no field equivalent.
* Scheduled alerts can now watch TBT. Existing INP alerts keep working and are migrated automatically.
* Fixed new Compare Results tests showing unavailable values for LCP, FCP, CLS, and TBT.
* Fixed stale Total Blocking Time values when re-running a test.
* Fixed the note about pre-1.19 interaction data alignment.
* Fixed individual Core Web Vitals field metrics not appearing when the overall assessment could not be calculated.
* Fixed the Core Web Vitals column remaining blank for passing pages and posts.
* Fixed values above 1,000 ms being misread when PageSpeed Insights used a thousands separator.
* Fixed a TBT value of exactly 0 ms showing as unavailable.
* Tests recorded before 1.19.0 retain their raw INP values, but they are not shown as TBT because the metrics are not comparable.
